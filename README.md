# Manas Chronicle — Individual Website Files

## Core files
- `index.html` — website structure and content
- `styles.css` — newspaper-inspired visual design and responsive layout
- `script.js` — smooth in-page navigation
- `Manas-Parab-Resume.pdf` — résumé PDF

## Image assets
The `assets/` folder contains:
- `portrait.webp`
- `at-work.webp`
- `mentoring.webp`
- `teaching-front.webp`
- `teaching-side.webp`
- `award.webp`

Keep the `assets` folder beside `index.html` so image paths continue to work.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder.

## Deploy
Upload this folder's contents to any static host such as Vercel, Netlify or GitHub Pages.
